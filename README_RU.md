# VK Leads Alarm (Android, тестовая версия)

Это **исходный проект**, а не готовый APK. Android SDK не был доступен в среде подготовки, поэтому APK не собран и запуск на настоящем Infinix не проверен.

## Что есть
- Android-приложение на Java: мониторинг через официальный `wall.get` VK API, категории ремонтных услуг, ссылки на свежие посты, история найденного.
- На первом успешном проходе посты запоминаются без тревоги. Далее отправляются только новые обнаруженные посты.
- Звонок через системную мелодию будильника **повторяется до ручного выключения**. Есть тестовая кнопка, выключение из уведомления.
- Список из 235 групп из ранее собранной базы, старт по умолчанию с первыми 10 группами.
- Все данные хранятся локально на телефоне. Автокомментарии и массовые подписки не делаются.

## Что нужно для реальной проверки
1. Рабочий доступ к VK API с правом читать стены выбранных публичных сообществ (`wall.get`). Действующий токен вводится **только в приложении**. Не присылайте его в чат и не размещайте в GitHub.
2. Собрать установочный APK в Android Studio или GitHub Actions.
3. Разрешить уведомления и убрать энергосбережение для приложения в XOS, чтобы повысить устойчивость фона.
4. Проверить реальную задержку на 10 группах, затем расширять. Охват 235 групп из одного телефона и быстрый отклик не гарантированы (лимиты API/батарея/сеть).

**Важно:** не любой пользовательский или сервисный токен позволяет читать любые стены ВК. При ошибке API приложение показывает код ошибки в статусе. Это тестовый прототип, а не готовый 24/7 продукт.

## Как собрать APK в Android Studio
1. Откройте папку `VK_Leads_Alarm_Android` как проект Android Studio.
2. Дождитесь синхронизации Gradle (нужен интернет для загрузки SDK и Gradle).
3. Выберите `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
4. APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Его можно установить на Android 13, разрешив установку из выбранного источника.

## Как собрать APK без Android Studio через GitHub Actions
1. Создайте **приватный** пустой GitHub-репозиторий.
2. Загрузите в него содержимое этой папки, включая `.github/workflows/build.yml` (загружайте **содержимое**, не внешнюю папку).
3. В разделе `Actions` запустите `Build debug APK` через `Run workflow` либо дождитесь сборки после загрузки файлов в `main`.
4. Скачайте артефакт `VKLeadsAlarm-debug-apk` (внутри будет `app-debug.apk`) и отправьте APK на Infinix.

## Первый запуск
1. Нажмите `Проверить громкий звонок`. Звук должен продолжаться до `Выключить звонок`.
2. Введите **только локально** валидный VK API-токен. Сохранение происходит по кнопке `Запустить мониторинг`.
3. Начните с 10 групп и интервала 60 секунд. Откройте статус по кнопке `Обновить список`.
4. Новые посты должны появляться в истории. При подходящем запросе зазвучит сигнал и появится уведомление со ссылкой.

### Технические ограничения
- При блокировке фонового сервиса оболочкой Infinix XOS мониторинг останавливается. Потребуются разрешённый автозапуск, отсутствие ограничений батареи и запуск foreground service.
- Нельзя гарантировать доставку за 15–60 секунд. ВК не даёт универсальных push-событий по стенам чужих групп; приложение опрашивает их по очереди.
- Если пост впервые появился уже на старте (до первого чтения), он считается старым и не отправляется.
- Широкие регулярные запросы могут упереться в ограничения VK API и не должны обходиться ротацией аккаунтов.
- Для настоящего производственного приложения нужны полноценная обработка жизненного цикла, настройка авторизации VK ID, защищённое хранение доступа, очередь уведомлений и тесты на устройствах.
